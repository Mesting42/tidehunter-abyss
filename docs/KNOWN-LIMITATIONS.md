# 已知限制与验证边界

- 已完成浏览器桌面、平板、手机横屏视口的实际交互测试；未持有实体 iPhone / Android / 平板，未验证 Safari、系统浏览器差异、真实多点触控延迟及震动硬件。
- 30 分钟生态持续性通过自动模拟验证；本轮真实主线累计 07:30，包含暂停、检查点恢复与重试，没有完成实体手机连续 30 分钟 GPU、发热、堆内存基准。
- 初始影礁实际通关使用正常商店强化和两件装备。无强化首领第一次尝试失败；未将其写成无强化通关证据。熟悉地图后的测试路线短于最初期望的 12～18 分钟，仍可通过敌人/任务参数继续做多玩家节奏平衡。
- 检查点恢复到区域安全点，重新构建生态、弹道与事件；不逐帧恢复全部生物。首领失败后从完整生命重新挑战。没有云存档、账号、联网排行榜、多人或手柄输入。
- 可选探索的收藏、机关和领取跨航次保存；尚未完成的信使跟随不保存瞬时位置，恢复后需重新交互开始。熟悉路线的开发者已完成全部探索，未进行陌生玩家的发现难度与平均时长测试。探索扩展后保留原主线通关证据及回归测试，没有再次完整重跑最终首领。
- 浏览器 localStorage 随来源隔离；切换端口 / 域名需要通过设置导出、导入存档。清除站点数据或隐私模式可能导致存档不保留。
- 需要 WebGL 与硬件加速；不支持 WebGL 的设备显示可操作的错误提示。较弱设备可在设置中选择低画质，仍需目标硬件实测。
- 模型、场景与音效采用原创程序化制作，走统一的暗海奇幻风格。音乐首次交互解锁；硬件音质和自动播放策略因浏览器不同需要目标平台复核。
- 静态版完全本地自包含，但需由 HTTP 静态服务加载；直接双击 file:// 不是正式启动方式。Three.js 分块超过 Vite 默认提示阈值，现阶段保留真实三维渲染并在文档披露。
