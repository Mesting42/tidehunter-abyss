# 可选探索扩展 · 视觉与交互契约

本文件记录「四海的回潮」扩展已经实现的局部设计，供后续维护使用。全局视觉规范仍以根目录 [DESIGN.md](../DESIGN.md) 与既有 [.impeccable/design.json](../.impeccable/design.json) 为准；此处不替代、复制或重新定义全局 token。产品范围见 [PRODUCT.md](../PRODUCT.md)，玩法、存档与程序职责见 [EXPLORATION.md](EXPLORATION.md)。

## Overview

延续「沉船上的航行记录」：Three.js 海域承担探索体验（Experience），记录页和海图承担查询、选择与追踪操作（Operate）。四条可选支线、四处奇景合计八处发现；四枚海域印记和两次途中遭遇各有独立计数。它们与原有十二项航次目标并存。

世界里的鱼群、微光、气泡、冰流和石碑先提供线索，记录页再承接已发生的发现。未知条目只显示海域和简短线索；具体地点名称、操作提示及可用追踪随实际进度出现。完成收集后仍可主动查看位置，便于回访。

## Colors

海墨底、骨白正文、冷玉生机与旧金关键状态沿用既有规范。探索使用青色方向提示，与主线旧金导航共同保留。以下是当前扩展的局部取值与用途，属于源码事实，不新增同名全局 palette token。

| 局部信号 | 当前取值 | 应用 |
| --- | --- | --- |
| 主动探索导航 | `#abe3ec`；圆环 `#ace1e5` | HUD 世界投影的箭头、距离和可见目标圆环 |
| 海图探索 | 未完成 `#a7d8e1`；已完成/记录 `#b9dfbd` | 仅已发现支线与奇景的方框 |

## Typography

沿用 Ma Shan Zheng 仪式性名称与中文无衬线操作信息的分工；探索记录本身的标题、说明、状态和数值使用既有无衬线字体。统计值为等宽数字，常规 22px，低矮横屏为 17px。支线标题常规 25px，低矮横屏为 22px；正文常规 14px / 1.6 行高，限制为 70ch。

海域、完成状态、当前操作分别呈现。按钮使用「追踪线索」「查看位置」「停止追踪」等动作文字，不以「已完成」代替仍可触发的操作名。

## Layout

记录页使用既有 `.panel-screen`：面板纵向滚动（`overflow-y: auto; touch-action: pan-y`），左右由 5vw 与设备安全区共同约束。海域画布仍固定铺满视口；记录内容在覆盖面板内滚动，不把游戏世界变成文档页面。

记录正文最大宽度 1120px。顶部为说明及三个独立统计；四条支线按海域排列，桌面每行由 64px 印记列、弹性说明列和 120px 行动列组成，列间距 24px。下部奇景与途中遭遇分为两栏，随后是四枚印记的收藏奖励。分组以留白、标题和细分隔线建立层级。

宽度不超过 1050px 时，支线列变为 54px / 弹性 / 108px，间距收紧。高度不超过 500px 的横屏缩小文字、印记和行内留白，保留操作高度。宽度不超过 600px 时，顶部统计另起一行，支线行动移到说明下方，奇景和遭遇变为单列，奖励行动移到说明之后。

记录页追踪按钮、奇景/遭遇按钮、暂停成对入口和海图记录入口均至少 44px 高；收藏奖励行动至少 48px 高。全局竖屏暂停与横屏恢复规则继续适用。

游动时探索 HUD 位于左侧任务下方，常规为左 28px、上 280px、宽 248px；低矮横屏为左 18px、上 181px、宽 188px。`src/ui/navigation.ts` 的 `navigationX()` 被主线和探索导航共用：常规保留左侧 320px、右侧 230px；高度低于 500px 时保留左侧 240px、右侧 180px，边界均受视口中点约束。方向箭头因此避开生命/目标栏、地图和触控区域。探索离屏提示同时限制纵向位置；可见目标在世界投影位置显示圆环。

## Elevation & Depth

真实模型、空间位置、地形遮挡与场景照明提供主要深度。记录页借用既有近实色海墨覆盖层，以细线与留白组织内容；方向文字只用局部文字阴影保护可读性，目标圆环使用轻阴影。

`src/exploration/render.ts` 以本地几何体构建珊瑚、锚座、锁链、三种石碑、印记底座、贝光、沉钟、冰晶和鲸骨；鱼群与信使复用已有生物模板。实体采用共享的 `MeshStandardMaterial`（当前默认粗糙度 0.58、金属度 0.08；指定自发光时强度 0.65）。水流使用透明 `LineSegments` 并复用位置缓冲区；涌流/平潮透明度为 0.32 / 0.11。它们属于世界呈现，不是面板背景装饰。

## Shapes

四枚印记是原创内联 SVG：统一六边外轮廓，内部各用线条、方框、放射线和菱形区分；54px 图形在低矮或窄屏收敛为 38px。轮廓随获得状态改变颜色，状态文字同时保留。

导航采用几何 SVG 箭头与圆环；海图采用方框表示已发现探索，与主线圆圈、宝藏菱形和玩家箭头保持形状差异。操作继续复用既有低圆角按钮和旧金焦点环。

## Components

### 记录条目与状态

| 条目状态 | 说明文字 | 行动 |
| --- | --- | --- |
| 支线尚未发现 | 未记录的回声、海域、等待发现及区域线索 | 禁用追踪 |
| 已发现且未完成 | 支线名、线索已发现、当前步骤和补充线索 | 追踪线索；已追踪时停止追踪 |
| 支线已完成 | 印记已收藏、完成后的说明、获得的彩色印记 | 查看位置；已追踪时停止追踪 |
| 奇景已记录 | 名称、海域与已记录 | 查看位置；已追踪时停止追踪 |
| 遭遇已完成 | 名称与赠礼已领取 | 查看位置；已追踪时停止追踪 |

未发现奇景和未见过的遭遇采用占位名称及原生禁用按钮。已发现但未记录奇景提供「前往记录」，已见但未完成遭遇提供「追踪」。当前追踪状态始终优先决定按钮文案；完成状态留在说明中。按同一条目的追踪行动再次操作会取消追踪，同一时间只追踪一个条目。

### HUD、海图与入口

右上罗盘、暂停页、海图以及港湾「纪录」均通向同一记录页。游动中打开记录页会暂停。附近已发现且未完成的支线可以出现「自由探索 · 附近线索」说明；青色世界方向标记只在主动追踪且存在目标时出现。HUD 标为「自由探索 · 追踪中」，箭头附带「支线」和米数；目标可见时转为圆环。首领战隐藏探索 HUD/标记，覆盖面板打开时也隐藏它们。

海图只为已发现的四条支线与四处奇景绘制方框，不预先铺出未知问号。主动追踪环可指向当前步骤或遭遇目标。图例明确写出「方框：探索」「青色：追踪」，记录入口同时显示发现与印记计数。

### 收藏奖励与训练说明

下部「四海的回潮」说明四印记解锁「回潮鳍纹」。未解锁时按钮显示印记进度且禁用；已拥有外观时显示「穿上回潮鳍纹」，训练中继续禁用该收藏操作。训练记录页顶部明确提示发现只作练习，不写入收藏。外观以双侧青色回潮纹和发光背鳍脉络呈现，使用独立模型节点。

### 环境信号

当前机关以细光环指向可响应步骤；珊瑚鱼群随步骤迁移，锚座破坏后从场景移除，回声庭保留已经回应的石碑信号。待收集印记缓慢旋转并轻微浮动，完成后隐藏。受困鱼群与信使在各自遭遇完成后退出探索表现。近处可交互时沿用「F / 交互」文字与触屏交互按钮。

## Do's and Don'ts

- **Do** 将世界线索、实际进度、记录说明和行动文案保持一致，完成后仍允许回访。
- **Do** 保持主线旧金与主动探索青色的语义区分，配合文字与形状共同说明状态。
- **Do** 让中央海域保留给游动、轮廓和攻击预警，继续使用共用导航边界与面板滚动。
- **Do** 继承原生禁用、可访问图标名称、旧金 `focus-visible`、主题滚动条和减少界面过渡规则。当前减少动态设置取消 CSS 过渡，不代表停止所有 Three.js 世界运动。
- **Don't** 把已完成写成按钮唯一文案而掩盖「查看位置 / 停止追踪」行为。
- **Don't** 把四个地域信号色或程序化世界材质扩充为全局操作色，或用整屏发光面板替代实体海域。
