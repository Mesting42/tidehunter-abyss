# 系统交接

## 入口与职责

所有模拟使用米与秒；x 向右、y 向下，海面 y=40，海床 y≈625。渲染层统一转换到 Three.js 的 y 向上坐标。主循环固定 60Hz，渲染独立；暂停清空累积时间，不补算离线饥饿或攻击。

| 文件 / 目录 | 职责 |
| --- | --- |
| `src/main.ts` | 初始化、固定时间步、渲染调度、WebGL 失败提示 |
| `src/types.ts` | 共享数据结构、状态与坐标约定 |
| `src/data.ts` | 鲨鱼、物种、地图地形、任务、装备、事件名称与世界尺寸 |
| `src/core/input.ts` | 键盘 / 鼠标 / Pointer Events；摇杆、冲刺各自指针生命周期 |
| `src/core/math.ts` | 几何、AABB 遮挡、圆碰撞推出、扫掠距离、随机种子 |
| `src/core/storage.ts` | 唯一存档键、默认值、导入校验、异常降级 |
| `src/core/audio.ts` | Web Audio 合成音乐与音效、独立音量、手势解锁 |
| `src/systems/movement.ts` | 加减速、朝向、惯性、冲刺、水面、重力、搁浅、胶囊近似地形碰撞 |
| `src/systems/combat.ts` | 实际鱼嘴、连续扫掠、前向判定、等级、机械门槛、弱点与每目标攻击间隔 |
| `src/systems/survival.ts` | 饥饿、伤害保护、连吃倍率、狂暴及结束保护 |
| `src/systems/ecology.ts` | 群鱼、逃散、避障、远近更新、补充、敌人状态机、精英与首领 |
| `src/systems/threats.ts` | 攻击预警时长、形状与锁定末段；由 AI 和 UI 共用 |
| `src/systems/progression.ts` | 新航次统计、任务进度、领取防重、游玩解锁 |
| `src/game.ts` | 系统编排、模式生命周期、事件、任务领取、技能、检查点与结算 |
| `src/render/models.ts` | 原创曲面模型、鳍、牙齿、机械、装备、合并几何体与共享模板 |
| `src/render/swimming.ts` | 三维朝向四元数、速度驱动尾摆；不修改模拟状态 |
| `src/render/renderer.ts` | 海域、镜头、灯光、粒子池、模型同步、海图与坐标投影 |
| `src/ui/ui.ts` | 港湾、HUD、商店、图鉴、任务、设置、存档备份与胜负界面 |
| `src/ui/threat-overlay.ts` | 攻击区、倒计时、来源外圈、收招提示和离屏箭头的 SVG 投影 |
| `src/ui/navigation.ts` | 主线 / 支线导航的水平安全区，避开左栏、海图与触屏按钮 |
| `src/exploration/` | 独立的可选支线、机关 / 奖励 / 存档规则、实体场景表现与探索记录页，详见 `EXPLORATION.md` |

| `tests/` | 规则、输入、暂停 / 结算、移动与预警回归检查 |

`Game` 拥有可变游戏状态，纯规则模块处理小范围职责，UI 和 Renderer 读取状态。渲染动画的时间、四元数和尾摆缓存保存在模型 `userData`，不回写碰撞、捕食或任务。`window.__TIDE__` 只提供冻结的只读诊断接口，没有跳关、修改成长或触发胜利入口。

## 关键边界

### 移动与表现

逻辑朝向由输入快速建立；大角度反向先减速，速度按指数阻尼衔接，避免全速沿旧朝向兜圈。松手阻尼保留短滑行。头、躯干与尾柄圆形检测共同近似胶囊，碰壁只清除碰撞轴速度，保留滑动。

不能把模型 `scale.y` 改为负值处理左右朝向。`swimOrientation()` 通过 yaw + 俯仰建立目标四元数，`rotateTowards()` 限制每帧旋转量；左右背鳍保持向上。镜头依据实际速度预留前方空间，原地朝向变化不会突然拉动镜头。

玩家显示改走 `animatePlayerSwimming()`，稳定俯仰限制为 60°，尾鳍独立跟随，并反算显示位置使嘴部对齐真实咬合点。敌鱼继续使用默认完整逻辑角度。玩家显示层位于岩石装饰前方，实际碰撞不变。参数、维护边界与本次实测见 [SWIM-POSE.md](SWIM-POSE.md)。

### 捕食与生存

`mouth()` 取鲨鱼前方 0.43 倍体长处，成长影响长度；扫掠连线覆盖上一帧至本帧嘴部路径。必须同时满足目标在前方、扫掠接触、地形不遮挡。目标自己的 `biteAt` 限制普通 0.42 秒 / 狂暴 0.22 秒咬合频率，死亡只处理一次。

等级控制能否处理目标，机械另需冲刺；首领不依靠普通等级门槛，而要求 `weak > 0` 和真实鳃口接触。狂暴增加两级、普通无敌、免费冲刺和分数；水雷仍危险。结束时 2.5 秒普通伤害保护并补充体力，禁止狂暴中回填槽形成无限循环。

### 敌人预警

`attackProfile()` 是预警时间、锁定时间、形状和范围的来源。普通敌鱼 0.7 / 0.76 秒，精英 1 / 1.05 秒；最后 0.22 / 0.25 秒固定 `e.angle`。`trackAttack()` 只在锁定前追踪，出招使用已锁定角度计算速度，不能重新瞄准玩家。隔墙或离开追击范围会取消普通敌鱼蓄力。

预警可视化使用屏幕 y 与模拟 y 同向的投影；不要再次对 `sin(angle)` 取负，避免攻击提示上下颠倒。UI 只表现现有状态，不承担伤害结算。收招不造成冲撞伤害；首领只有此时鳃口可受伤。

### 检查点和经济

领取标记存于 `stats.claims`，任务、宝藏、区域、精英、胜利各有唯一键。分数兑换记录 `paidScore` 的差值，航次数使用 `runCounted` 防止恢复检查点重复计数。结算有独立幂等标记，胜利继续生存可重新结算新增分数，但不重复发放胜利奖励。

检查点保存区域安全坐标、任务、成长、正常狂暴蓄力、宝藏、破坏地形和精英领取标记。恢复后重新种植生态并移除附近危险；不序列化每条鱼、瞬时弹道、活跃狂暴和事件。训练退出恢复原出航鲨鱼，不改真实货币、图鉴、纪录和解锁。

可选探索使用存档内独立的 `exploration` 收藏与机关记录，不加入原十二项目标。每次发现、触发或领取即时持久化，重建世界时同步门和捷径。训练使用副本；真实收藏、一次奖励与四印记外观不受训练污染。旧 v1 档缺字段时自动补齐。未完成的信使跟随在重开世界后从起点交互开始，不保存逐帧位置。具体配置、扩展清单与测试证据见 [EXPLORATION.md](EXPLORATION.md)。

## 扩展步骤

### 新鲨鱼

1. 向 `SHARKS` 添加完整 `SharkDef`，使用唯一 id。
2. 在 `sharkModel()` 添加体形差异，保留 tail / jaw 等活动节点；使用当前模板合并流程。
3. 在 `Game.skill()` 明确实现技能与持续状态；如改变移动或免疫，在对应规则层读取。
4. 在 `unlockedByPlay()` 增加正常解锁条件，并更新商店说明与存档白名单。
5. 通过训练正常试游；检查体长碰撞、嘴部位置、跃水和四向朝向。

### 新目标或敌人

向 `SPECIES` 添加参数，在 `creatureModel()` 建模，在 `Ecology.seed()` 或事件加入生成位置。新增规则先扩展 `FoodRule` 并在 `combat.ts` 明确处理。新增主动攻击必须同步 `attackProfile()`、状态机和投影形状；加入“提示与实际轨迹一致”的测试，不能只添加一个红色装饰标记。

### 新区域与任务

区域判定在 `regionAt()`，显示信息在 `REGIONS`，地形在 `TERRAIN`。当前世界尺寸固定，扩展边界还需同步碰撞限制、相机、海图和安全点。新任务同时更新 `TASKS`、`RunStats` 默认值、`taskProgress()` 和触发统计；领取继续使用唯一任务 id。

### 新事件与装备

事件生命周期在 `Game.updateEvents()`，先预告再生成，必须有硬上限和清理边界。装备数据在 `EQUIPMENT`，真正效果由移动、生存或表现层显式读取；继续限制最多两件。修改说明时同时核对真实倍率，防止文案与代码漂移。

## 平衡与性能

- 鲨鱼生命、饥饿、咬合、游速与等级：`data.ts`；咬合强化每级 +14%，游速每级 +5.5%，最多三级。
- 初始 15 秒无饥饿，首领饥饿按常规四分之一计算；训练无压力只在训练模式生效。
- 饥饿与伤害数值见 `survival.ts`，局部补充与远处简化见 `ecology.ts`。
- 实体硬上限 360，普通远处实体每半秒更新；弹道上限 90，粒子上限 240。几何和材质按模板复用，临时地形与胜利材质主动释放。
- DPR 自动上限 1.65，高画质上限 2，低画质 1；不使用高成本实时阴影与后处理。
- 调整攻击时间同时检查预警长度、末段锁定、攻击实际速度与收招；不要只缩短 UI 倒计时。
