# 可选探索扩展：四海的回潮

用户确认 B 方案后实施：在原有十二项目标之外，让海域有可发现、可解谜、可回访的支线。全部位置仍在同一张连通地图中，没有传送到独立关卡，也不要求完成支线才能挑战主线首领。

本扩展的局部视觉与交互契约见 [EXPLORATION-DESIGN.md](EXPLORATION-DESIGN.md)；根目录 [DESIGN.md](../DESIGN.md) 继续作为全局视觉规范。

## 玩家入口

游动时点击右上罗盘，或从暂停菜单、海图、港湾的「纪录」打开「探索记录」。跟随微光、气泡、冰流和石碑发现线索后，记录页才允许追踪具体位置。海图方框只显示已发现的地点；青色导航属于主动追踪的探索，金色导航仍属于当前航次目标。

靠近可交互地点时出现 F / 交互提示。珊瑚和冰纹通过靠近触发，锁链锚座必须正面冲刺撞断，回声碑和印记需要交互。支线附近仍有生存压力，应顺路捕食，留意短暂蓄力预警与回气窗口。

## 四条海域支线

| 海域 / 支线 | 主要操作 | 完成后的变化 |
| --- | --- | --- |
| 日光浅湾 · 珊瑚回声 | 沿发光鱼群依次靠近三簇回应的珊瑚，进入开启的暗室，交互收集 | 珊瑚印记、45 潮晶，暗室保持开放 |
| 沉船航道 · 失落的密舱 | 正面冲刺撞断两处锁链锚座，从东侧进入，交互收集 | 沉船印记、45 潮晶，舱底开启通向深海的真实捷径 |
| 冰冷外海 · 逆流冰隙 | 顺序经过三道冰纹；利用平潮冲刺，在中段避流岩隙恢复体力，再进入末端密室 | 霜潮印记、45 潮晶，上方冰层出口开启 |
| 裂渊深海 · 沉眠的回声庭 | 按「波纹 → 双环 → 菱晶」顺序交互；唤醒错误碑不会清空已经完成的顺序 | 东门开启，可绕开守卫进入；裂渊印记、45 潮晶 |

冰隙每 7 秒循环一次，涌流持续 4.6 秒、平潮持续 2.4 秒。涌流实际改变鲨鱼移动并接受地形碰撞，避流岩隙不会推流，并额外恢复每秒 26 点体力。完成逆流支线后，可以从新出口前往冰海鲸歌。

四枚印记解锁外观「回潮鳍纹」。在记录页点击「穿上回潮鳍纹」，或在「鲨鱼与进化」选择；这项收藏奖励不出售，也不改变战斗数值。

## 奇景与途中遭遇

四处奇景为贝光花园、沉钟回廊、冰海鲸歌、古鲸眠骨。各自需要靠近发现，再交互记录，每处一次奖励 12 潮晶。四条主要支线与四处奇景合计八处发现。

- 解救受困鱼群：调查异常微光，冲刺撞开渔网，鱼群获救后提供可捕食补给，奖励 18 潮晶。直接在近处撞开渔网也能正常完成。
- 潮汐信使：交互回应发光鱼，跟随四段路线。离得太远时信使停下等待；到终点后留下补给，奖励 18 潮晶。

两次途中遭遇独立统计，不增加八处地标的计数。

## 程序职责与扩展位置

| 文件 | 职责 |
| --- | --- |
| `src/exploration/data.ts` | 支线、节点、奇景、遭遇与实体地形的配置；坐标单位为米，y 向下 |
| `src/exploration/system.ts` | 发现、顺序、门与捷径、逆流、遭遇、奖励幂等和旧档清洗 |
| `src/exploration/render.ts` | 珊瑚、锚座、石碑、印记、信使与缓冲区复用的水流表现 |
| `src/exploration/journal.ts` | 记录页的状态与语义化按钮，不修改世界 |
| `src/exploration/style.css` | 记录页、HUD、方向提示及横屏适配 |
| `src/ui/navigation.ts` | 为方向提示保留 HUD、地图与触屏区域，防止提示遮住文字 |
| `tests/exploration.test.ts` | 机关、奖励、兼容、训练边界、遭遇与路径可达性回归 |

`Game.explorationContext()` 是世界能力边界：提供玩家、地形和实体，以及保存、奖励、提示、生成补给、解锁回调。探索系统不依赖 Game 实例或音频实现；渲染层只读取进度。移动系统通过可选流速参数接收逆流，不在渲染中推动玩家。

新增支线时先定义唯一 id、入口、节点、目标和对应门，确认路径与视线遮挡，再扩展存档白名单、记录页、渲染和用例。当前产品固定为四枚海域印记、八处发现；增加数量时需同步更新 UI 和解锁条件，不应只向数组追加。

## 存档与奖励边界

仍使用 `tidehunter.abyss.save.v1`。新增 `exploration` 保存已发现 / 已完成 id、机关步数、已断锚座、领取标记、遭遇完成和主动追踪。旧档缺少字段时补默认值，未知 id 和异常步数被清洗，原货币、主线与装备保持兼容。

收藏、机关和奖励跨航次保存，领取按唯一 id 防重。普通航次失败后，支线收藏不会丢失；不序列化活跃信使每一帧的位置，未完成的跟随在恢复后重新交互开始。训练使用探索副本，发现与印记只作练习，不发放真实货币、解锁或收藏。

## 实测证据

2026-10-24，通过静态预览 5193 的真实 UI / WASD / Shift / E / F，用初始影礁、无强化与装备，完成四条支线、四处奇景、两次遭遇。记录页显示 **8 / 8 发现、4 / 4 印记、2 / 2 遭遇**，当时航次计时 **02:23**，得分 **1,012**。此路线由熟悉地图的开发者完成，含暂停，不代表首次玩家平均时长或主线通关时长。

实际穿过沉船舱底和冰层出口；冰隙避流区将体力从 12% 恢复到 100%；石庭守卫可绕行。穿戴新外观后刷新并恢复检查点，收藏和外观保留。最后通过游戏设置导入不含 exploration 的旧版初始备份，正常显示 80 潮晶、0 / 8 探索，预览已恢复干净起点。

正常导出的完整验收存档保存在 [qa/exploration-complete.json](qa/exploration-complete.json)。这是开发验收材料；若自行导入，会替换当前来源的游戏存档，请先用游戏设置导出自己的备份。正式交付不自动载入这份文件。
