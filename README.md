# 猎潮狂鲨 · 裂渊航次

一款原创侧视 2.5D 浏览器海洋动作生存游戏。使用 TypeScript、Three.js 与 Vite；模型、地形、特效和音效在本地生成，中文标题字体自托管，无运行时远程素材依赖。

## 启动与构建

建议 Node.js **22.12 或以上的 22.x 版本**；本次使用 22.18.0。

从 GitHub 获取源码：

```powershell
git clone https://github.com/Mesting42/tidehunter-abyss.git
cd tidehunter-abyss
npm ci
npm run dev
```

仓库包含源码、测试、文档和实测截图；`node_modules/`、`dist/`、本地 `delivery/` 压缩包及运行临时目录不纳入 Git。构建发布文件请运行 `npm run build`。

已在本机目录交付时，也可直接启动：

```powershell
cd D:\AnLi\猎潮狂鲨
npm ci
npm run dev
```

开发预览：<http://127.0.0.1:5186/>。

```powershell
npm test
npm run build
npm run preview
```

静态版预览：<http://127.0.0.1:5193/>。`dist/` 是完整静态站点，可部署到普通 HTTP 静态服务器；`base: "./"` 支持子目录。请通过 HTTP 访问，直接双击 `index.html` 的 `file://` 模式不能可靠加载 ES modules。严格端口若被占用，可用 `npm run preview -- --port 5194`，不要停止其他项目的服务。

`delivery/猎潮狂鲨-静态版.zip` 包含 `dist/` 与说明文档；发布时将 `dist/` 内的文件作为站点根目录。`delivery/猎潮狂鲨-源码.zip` 包含源码、配置、锁文件、测试、许可和交接文档，不含可重新安装的 `node_modules/`。

交付时正在运行 5186 开发服务和 5193 静态预览服务；在这两个服务仍运行时不需要重复启动。切换端口会改变浏览器存档所属来源，可在设置中导出、导入备份。

## 可玩内容

- **目标探索、无尽猎食、自由训练**三种模式。训练可试游四种鲨鱼，且可关闭训练饥饿与伤害。
- **日光浅湾、沉船航道、冰冷外海、裂渊深海**四片连通海域；沉船捷径、岩壁、洞穴、遗迹、海面与空中运动。
- **影礁、逐电、沉甲、幽烬**四种原创鲨鱼，具有独立外形、属性与专属技能。
- **18 类目标**：群鱼、大鱼、鳐、蟹、水母、海胆、敌鲨、鮟鱇、鳗、乌贼、海燕、船、鱼叉台、水雷、渔网、两名精英与最终巨鳗。
- 自动咬食与高速嘴部扫掠、冲刺破坏、等级门槛、持续饥饿、成长、连吃倍率、12 秒狂暴与结束保护。
- **12 项递进目标、6 处宝藏、4 种事件、2 名区域精英、两阶段三招式最终首领**。
- **四条可选海域支线、四处奇景、两次途中遭遇**：珊瑚暗室、沉船密舱与舱底捷径、逆流冰隙、回声石庭；已发现地点追踪与独立探索记录，集齐印记解锁「回潮鳍纹」。
- 潮晶、正常游玩解锁、三级有限强化、5 件装备（二选二）、月蚀外观、图鉴、分模式纪录、本地存档与备份。
- 暂停、后台与竖屏保护；键盘、可选鼠标跟随、独立指针摇杆与冲刺按钮。

## 操作

| 操作 | 桌面 | 手机 / 平板横屏 |
| --- | --- | --- |
| 游动 | WASD / 方向键；设置可启用鼠标跟随 | 左下虚拟摇杆 |
| 冲刺 | 按住 Shift / 鼠标右键，同时提供游动方向 | 按住右下冲刺，可与摇杆同时按住 |
| 专属技能 | E | 技能按钮 |
| 收集 / 进入祭场 | F | 交互按钮 |
| 地图 | M / 地图按钮 | 地图按钮 |
| 暂停 / 返回海域 | Esc / 暂停按钮 | 暂停按钮 |

朝向迅速响应，掉头短暂减速，松手保留少量惯性。左右通过三维转身保持背鳍朝上，尾部摆动随游速变化。冲刺向上可跃出水面；离水后受重力影响。

普通敌鱼蓄力约 **0.7～0.76 秒**，精英约 **1～1.05 秒**。红色外圈、倒计时及方向通道对应实际攻击；预警末段锁定方向，侧移躲避后可利用薄荷色收招窗口反击。离屏威胁显示边缘箭头。水雷仍需躲避，狂暴不免除水雷伤害。

## 第一次航次提示

先沿浅湾追逐银鳞群鱼，按任务提示练习冲刺和跃出水面收集。地图金圈标出当前目标，宝藏需要靠近后交互。渔网要正面冲刺撞断；普通咬食不能破坏机械。

狂暴中可安全处理更高等级的普通危险目标。狂暴结束会补充体力并给予短暂保护；随后仍需捕食补血。第 7 项“狂潮连猎”累计计算多次狂暴中的目标，不要求一次吃满。

首领战在最后一项任务时由祭场入口交互开启。留意冲撞、放电和尾击的不同预警，借柱子挡弹；**仅鳃口暴露时才能伤害首领，必须用嘴部接触真实弱点**。附近敌鱼也能作为补给，但需先观察攻击。失败后从安全检查点继续，已领取的宝藏与任务不会重复奖励。

## 存档

唯一键：`tidehunter.abyss.save.v1`，不触碰其他项目的数据。探索航次保存安全点、任务、成长、宝藏、已开通路与精英完成标记；恢复时重新构建生态和事件，不还原每一条鱼的瞬时位置。首领失败后重新挑战完整首领。

设置中可导出 / 导入 JSON。训练不发放货币、解锁与纪录；真实航次和训练的进度边界分开。存档异常会提示并回退，不会清空其他 localStorage 键。
